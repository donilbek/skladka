# Складка

Архиватор файлов и папок для браузера и Windows. Данные сжимаются на устройстве. При распаковке «Складка» проверяет SHA-256 и восстанавливает имена файлов и структуру папок.

## В браузере

Скачайте `index.html` и откройте его в браузере. Выберите файл или перетащите папку в окно, затем сохраните архив `.skl`. Чтобы восстановить данные, выберите **Распаковать**. Для публикации сайта разместите `index.html` на статическом хостинге.

## На Windows

Скачайте и запустите `Skladka.exe`. Установка и API-ключ не требуются. Для архива папки приложение предложит выбрать каталог для сохранения.

## HTTP API

Для запуска сервиса установите ASP.NET Core Runtime, указанный в `server/Skladka.Api.runtimeconfig.json`. Из корня репозитория выполните

```sh
dotnet server/Skladka.Api.dll
```

По умолчанию сервис доступен на `http://127.0.0.1:8787`. Метод `GET /v1/health` проверяет доступность. Для сжатия отправьте исходные байты на `POST /v1/compress`, для распаковки отправьте архив на `POST /v1/decompress`. Используйте тип содержимого `application/octet-stream`.
